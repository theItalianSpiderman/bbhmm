# BBHMM v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** En fristående webbsida som visar "kvar" av en startsumma, låter användaren lägga till/ta bort poster och sparar allt i localStorage – byggd för iPhone stående, i Departure Mono med box drawing-tecken.

**Architecture:** Vanilla HTML/CSS/JS med ES-moduler, inga beroenden i runtime. Ren logik (belopp, lagring, tabellrendering) ligger i små moduler som testas med Nodes inbyggda testrunner; `app.js` kopplar logiken till DOM. Hostas statiskt på GitHub Pages.

**Tech Stack:** HTML, CSS, JavaScript (ES2022-moduler), `node --test` (Node 26, inga npm-paket), Departure Mono woff2 (OFL).

**Spec:** `docs/superpowers/specs/2026-11-15-bbhmm-v1-design.md`

## Global Constraints

- Inga runtime-beroenden, ingen build-steg; inga externa nätverksanrop (font bundlas i repot).
- All data stannar i webbläsaren: localStorage-nyckel `bbhmm.v1`.
- Belopp lagras som heltal i ören.
- Visningsformat: `1 234,50` (mellanslag som tusentalsavgränsare, komma som decimal, alltid två decimaler); negativt som `-1 234,50`. Datum `ÅÅÅÅ-MM-DD`.
- Inmatning accepterar både `,` och `.` som decimaltecken samt mellanslag.
- Negativt belopp i en post = pengar in (ökar kvar). `kvar = start − summa(poster)`.
- Lista sorterad på datum stigande, nyast längst ner; samma datum → insättningsordning.
- Måste fungera i iPhone stående (~390pt bredd), respektera safe-area, öppnas i helskärm från hemskärmen.
- Allt UI-text på svenska.
- Commits: inga `Co-Authored-By`-rader. Committa bara efter användarens godkännande (se användarens CLAUDE.md).

## Review Focus

1. **Konstig beloppsinmatning** (`""`, `"abc"`, `"0"`, `"1 234,5"`, `"12.345"` (>2 decimaler avvisas), `"-500"`, `"1,2,3"`) → giltiga tolkas rätt, ogiltiga/noll avvisas utan att något sparas. Test i Task 1.
2. **Trasig/otillgänglig localStorage** (korrupt JSON, `getItem` kastar i privat läge) → appen startar med tomt läge i stället för att krascha. Test i Task 2.
3. **Dagens datum i fel tidszon** – `toISOString()` ger gårdagens datum sent på kvällen i UTC+1. `todayISO()` måste använda lokal tid. Test i Task 1.
4. **Lång anteckning / stora belopp** → kolumnerna förblir raka; anteckning kapas med `…`, beloppskolumnen räcker för största beloppet. Test i Task 3.
5. **Negativt kvar** (mer utgifter än start) → visas som `-123,45`, inte `NaN` eller tomt. Test i Task 1 + 2.

### Task 1: Belopp och datum (`money.js`)

**Files:**
- Create: `package.json`, `js/money.js`

**Interfaces:**
- Produces:
  - `parseAmount(input: string) -> number | null` – ören (heltal), `null` om ogiltigt eller 0.
  - `formatAmount(ore: number) -> string` – t.ex. `123450 → "1 234,50"`, `-5 → "-0,05"`.
  - `todayISO(now?: Date) -> string` – lokal `ÅÅÅÅ-MM-DD`.

- [ ] **Step 1: Skriv failande tester**

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { parseAmount, formatAmount, todayISO } from '../js/money.js';

test('parseAmount accepterar svenska och engelska format', () => {
  assert.equal(parseAmount('1 234,5'), 123450);
  assert.equal(parseAmount('12.34'), 1234);
  assert.equal(parseAmount('250'), 25000);
  assert.equal(parseAmount('-500'), -50000);
  assert.equal(parseAmount(' 0,05 '), 5);
});
test('parseAmount avvisar ogiltigt och noll', () => {
  // fler än två decimaler avvisas (”1.234” är tvetydigt: tusental eller decimal?)
  for (const s of ['', '   ', 'abc', '0', '0,00', '1,2,3', '12a', '-', '12.345', '1.234']) {
    assert.equal(parseAmount(s), null, s);
  }
});
test('formatAmount', () => {
  assert.equal(formatAmount(123450), '1 234,50');
  assert.equal(formatAmount(0), '0,00');
  assert.equal(formatAmount(-12345), '-123,45');
  assert.equal(formatAmount(999999999), '9 999 999,99');
});
test('todayISO använder lokal tid', () => {
  assert.equal(todayISO(new Date(2026, 10, 15, 23, 59)), '2026-11-15');
  assert.equal(todayISO(new Date(2026, 0, 3, 0, 1)), '2026-01-03');
});
```

### Task 2: Lagring och kvar (`store.js`)

**Files:**
- Create: `js/store.js`
- Test: `tests/store.test.js`

**Interfaces:**
- Consumes: inget (lagrar ören och ISO-datumsträngar).
- Produces: `createStore(storage: {getItem, setItem}) -> Store`, där
  - `store.state -> { start: {amount: number, date: string} | null, entries: Entry[] }`
  - `Entry = { id: string, date: string, amount: number, note: string, seq: number }`
  - `store.setStart(amount: number, date: string) -> void`
  - `store.addEntry({date, amount, note}) -> Entry`
  - `store.removeEntry(id: string) -> void`
  - `store.sortedEntries() -> Entry[]` – datum stigande, sedan `seq`
  - `store.balance() -> number` – `start.amount − Σ entry.amount` (0 om start saknas)
- Varje mutation sparar direkt som JSON under nyckeln `bbhmm.v1`.

- [ ] **Step 1: Skriv failande tester** – med en fake-storage (`Map`-baserad):

```js
test('balance = start minus poster, negativ post ökar', () => {
  const s = createStore(fakeStorage());
  s.setStart(100000, '2026-11-01');
  s.addEntry({ date: '2026-11-02', amount: 25000, note: 'Mat' });
  s.addEntry({ date: '2026-11-03', amount: -5000, note: 'Retur' });
  assert.equal(s.balance(), 80000);
});
test('balance kan bli negativ', () => {
  const s = createStore(fakeStorage());
  s.setStart(1000, '2026-11-01');
  s.addEntry({ date: '2026-11-02', amount: 13345, note: '' });
  assert.equal(s.balance(), -12345);
});
test('sortering: datum, sedan insättningsordning', () => {
  const s = createStore(fakeStorage());
  const a = s.addEntry({ date: '2026-11-05', amount: 1, note: 'a' });
  const b = s.addEntry({ date: '2026-11-02', amount: 1, note: 'b' });
  const c = s.addEntry({ date: '2026-11-05', amount: 1, note: 'c' });
  assert.deepEqual(s.sortedEntries().map(e => e.note), ['b', 'a', 'c']);
});
test('removeEntry och persistens över ny store', () => {
  const st = fakeStorage();
  const s = createStore(st);
  s.setStart(5000, '2026-11-01');
  const e = s.addEntry({ date: '2026-11-02', amount: 100, note: 'x' });
  s.addEntry({ date: '2026-11-03', amount: 200, note: 'y' });
  s.removeEntry(e.id);
  const s2 = createStore(st);
  assert.equal(s2.state.entries.length, 1);
  assert.equal(s2.balance(), 4800);
});
test('korrupt JSON eller kastande storage ger tomt läge', () => {
  assert.deepEqual(createStore(fakeStorage({ 'bbhmm.v1': '{nope' })).state, { start: null, entries: [] });
  const throwing = { getItem() { throw new Error('denied'); }, setItem() { throw new Error('denied'); } };
  const s = createStore(throwing);
  assert.deepEqual(s.state, { start: null, entries: [] });
  s.setStart(100, '2026-11-01'); // får inte kasta
  assert.equal(s.balance(), 100);
});
```

### Task 3: Box drawing-rendering (`table.js`)

**Files:**
- Create: `js/table.js`
- Test: `tests/table.test.js`

**Interfaces:**
- Consumes: `formatAmount` (Task 1), `Entry` (Task 2).
- Produces:
  - `layout(cols: number, entries: Entry[]) -> {date: 10, amount: number, note: number}` – `amount` = max(9, längsta formaterade belopp); `note` = `cols − date − amount − 1 (×-kolumn) − 5 (kantlinjer)`, minst 4.
  - `fit(text: string, width: number) -> string` – räknar kodpunkter (`Array.from`), kapar med `…`, fyller ut med mellanslag till exakt `width`.
  - `rowCells(entry: Entry, lay) -> {date: string, amount: string, note: string}` – redan utfyllda/kapade; belopp högerställt.
  - `topLine(lay)`, `bottomLine(lay) -> string` – `┌──┬──┬──┬─┐` resp. `└──┴──┴──┴─┘`.
  - `boxLines(lines: string[], cols: number) -> string[]` – dubbelram `╔═╗ ║ ║ ╚═╝` runt headern, varje rad exakt `cols` tecken.

- [ ] **Step 1: Skriv failande tester**

```js
test('fit kapar och fyller ut på kodpunkter', () => {
  assert.equal(fit('Mat', 6), 'Mat   ');
  assert.equal(fit('Hyra del två', 8), 'Hyra de…');
  assert.equal(Array.from(fit('Kaffe ☕ och bulle', 7)).length, 7);
});
test('layout fyller exakt cols och beloppskolumnen växer', () => {
  const small = layout(36, [{ amount: 25000 }]);
  assert.equal(small.date + small.amount + small.note + 1 + 5, 36);
  const big = layout(36, [{ amount: 999999999 }]);
  assert.equal(big.amount, '9 999 999,99'.length);
  assert.ok(big.note >= 4);
});
test('rowCells högerställer belopp', () => {
  const lay = layout(36, [{ amount: 25000 }]);
  const c = rowCells({ date: '2026-11-02', amount: 25000, note: 'Mat' }, lay);
  assert.equal(c.amount, '250,00'.padStart(lay.amount));
  assert.equal(c.date, '2026-11-02');
});
test('linjer har samma bredd som rader', () => {
  const lay = layout(36, []);
  assert.equal(Array.from(topLine(lay)).length, 36);
  assert.equal(Array.from(bottomLine(lay)).length, 36);
  boxLines(['KVAR', '12 345,67'], 36).forEach(l => assert.equal(Array.from(l).length, 36));
});
```

### Task 4: Sidan (`index.html`, `style.css`, `app.js`, font, manifest)

**Files:**
- Create: `index.html`, `css/style.css`, `js/app.js`, `manifest.webmanifest`, `icon.png`, `fonts/DepartureMono-Regular.woff2`, `fonts/LICENSE`

**Interfaces:**
- Consumes: allt från Task 1–3.

**Font:** hämta `DepartureMono-Regular.woff2` + `LICENSE` från den officiella releasen på GitHub (`rektdeckard/departure-mono`, länkad från departuremono.com). **Fråga användaren innan nedladdning** (filnamn, källa, storlek). Kontrollera att box drawing-tecknen (`┌┬┐│└┴┘╔═╗║╚╝`) och de valda ikontecknen finns i fonten; välj annars andra tecken.

**Beteende (bestämt i spec):**
- `<header>` `position: sticky; top: 0` med dubbelram via `boxLines`: rad 1 `START <belopp>  <datum>` (liten), rad 2 `KVAR` + belopp (stor, t.ex. 2× fontstorlek). Tryck på headern öppnar start-formuläret.
- Utan `start` i store: start-formuläret visas direkt vid laddning och kan inte avbrytas.
- Listan: varje rad är ett element med text i cellerna och en `×`-knapp i sista kolumnen (`aria-label="Ta bort"`), ingen bekräftelse. Tom lista: visa en rad `inga poster`.
- `+`-knapp fast nere till höger (ovanför safe-area). Öppnar ett bottenark: belopp (`inputmode="decimal"`), datum (`type="date"`, förvalt `todayISO()`), anteckning (`maxlength="60"`). Ikoner: spara (`✓`) och ångra (`✗`). Ogiltigt belopp → beloppsfältet markeras, inget sparas.
- Efter laddning och efter tillägg: scrolla till botten (`scrollIntoView` på sista raden).
- `cols` beräknas från viewporten: mät bredden på ett tecken i ett dolt `<span>` och ta `floor(tillgänglig bredd / teckenbredd)`; rendera om vid `resize`. Fontstorlek väljs så att `cols ≥ 34` på 390pt-bredd.
- Head: `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`, `apple-mobile-web-app-capable`, `apple-mobile-web-app-status-bar-style=black-translucent`, `apple-touch-icon`, `theme-color`, länk till manifest (`display: standalone`, `name: "BBHMM"`). `padding: env(safe-area-inset-*)`.
- Inputs har `font-size ≥ 16px` (annars zoomar iOS Safari vid fokus).
